Como Usar
1. Incluir CSS e JS
<link rel="stylesheet" href="{{ url_for('static', filename='css/table.css') }}">
<script src="{{ url_for('static', filename='js/datatable.js') }}"></script>
2. Estrutura HTML Básica
<div class="table-container">
  <div class="table-header">
    <div class="table-search">
      <i class="bi bi-search"></i>
      <input type="text" class="table-search-input" placeholder="Buscar...">
    </div>
  </div>

  <div class="table-responsive">
    <table class="table-modern">
      <thead>
        <tr>
          <th data-sortable="true" data-type="string">Coluna</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td data-label="Coluna">Valor</td>
        </tr>
      </tbody>
    </table>
  </div>

  <div class="table-footer">
    <div class="table-info"></div>
    <nav class="pagination-nav"></nav>
    <select class="per-page-select"></select>
  </div>
</div>
3. Atributos de Colunas
  • data-sortable="true" - Habilita ordenação na coluna
  • data-type="string|number|date" - Define tipo de dados para ordenação correta
  • data-sort-value - Valor customizado para ordenação (opcional)
  • data-label - Label para modo mobile (obrigatório para responsividade)
4. Inicialização Manual (Opcional)
const table = document.querySelector('.table-modern');
const dt = new DataTable(table, {
  sortable: true,
  searchable: true,
  perPage: 20,
  pagination: true
});
