File Upload System

Exemplos completos de uso do sistema modernizado de upload

1. Upload de Imagem Única

Upload simples de uma imagem com preview automático. Aceita: image/* | Tamanho máx: 5MB

0%

2. Upload de Documentos (PPT/PDF)

Upload de apresentações e documentos com ícone apropriado. Aceita: .ppt, .pptx, .pdf | Tamanho máx: 16MB

0%

3. Upload de Múltiplas Imagens

Upload de várias imagens ao mesmo tempo com grid de previews. Aceita: image/* | Múltiplas: sim

0%

4. Upload Compacto (Ficha Técnica)

Versão compacta para formulários com múltiplos uploads. Aceita: .pdf, .doc, .docx, .xlsx, .xls

0%

5. Importar Excel

Upload específico para arquivos Excel. Aceita: .xlsx, .xls

0%

Guia de Uso

HTML Básico

<div class="upload-zone">
  <input
    type="file"
    id="myFile"
    name="file"
    accept="image/*"
    hidden
  >
  <label for="myFile" class="upload-label">
    <div class="upload-icon">
      <i class="bi bi-cloud-upload"></i>
    </div>
    <div class="upload-text">
      <p class="upload-title">Título</p>
      <p class="upload-subtitle">Subtítulo</p>
      <p class="upload-formats">Formatos</p>
    </div>
  </label>
  <div class="upload-preview" style="display: none;"></div>
  <div class="upload-progress" style="display: none;">
    <div class="progress-bar">
      <div class="progress-fill"></div>
    </div>
    <span class="progress-text">0%</span>
  </div>
</div>

JavaScript (Automático)

O sistema inicializa automaticamente ao carregar a página. Todas as zonas com a classe .upload-zone são configuradas.

Opções via Data Attributes

  • data-max-size - Tamanho máximo em bytes
  • data-show-preview - true/false
  • data-simulate-upload - true/false

Validações Implementadas

Tipo de Arquivo

Valida extensão e MIME type. Aceita wildcards (image/*) e extensões específicas (.pdf, .xlsx)

Tamanho do Arquivo

Limite configurável via data-attribute. Padrão: 5MB para imagens, 16MB para documentos

Preview Inteligente

Exibe imagem para arquivos image/*. Para outros tipos, mostra ícone apropriado (PDF, Excel, etc)

Drag & Drop

Arraste arquivos diretamente do explorador de arquivos. Visual feedback durante o arrasto

Múltiplos Arquivos

Suporte para upload de múltiplos arquivos simultaneamente com grid de previews

Mensagens de Erro

Feedback claro para usuários quando arquivo não atende aos requisitos
