## 📚 Glossário de Termos

- **Design Token**: Variável CSS reutilizável (ex: `--primary`)
- **Classe Base**: Classe obrigatória (ex: `.btn` para botões)
- **Modificador**: Classe que altera estilo (ex: `.btn-sm`)
- **Variante**: Versão diferente (ex: `.btn-outline-primary`)
- **Utilitário**: Classe de propósito único (ex: `.d-flex`)

## 🔧 Troubleshooting

### Componente não aparece estilizado?
✅ Verificar se `components.css` está incluído
✅ Verificar caminho do arquivo CSS
✅ Verificar se classe base está presente (ex: `.btn`)

### Cores não funcionam?
✅ Verificar se variante está correta (ex: `.btn-primary`)
✅ Verificar override de estilos personalizados

### Responsividade não funciona?
✅ Verificar tag `<meta name="viewport">` no HTML
✅ Componentes são mobile-first por padrão
